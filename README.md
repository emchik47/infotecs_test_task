# Logger

Библиотека для логирования на C++ с поддержкой вывода в файл и отправки по сети (TCP-сокеты).

## Возможности
* Поддержка различных уровней логирования: INFO(0), WARNING(1), ERROR(2).
* **FileLogger**: Запись логов в локальный файл.
* **SocketLogger**: Отправка логов на удаленный сервер.(WIP)

## Сборка проекта
Проект использует систему сборки CMake.

Только библиотека:
cmake --build build --target logger_lib

Консольное приложение для записи сообщений в текстовый файл:
cmake --build build && ./build/app <filename> <default prioriry level>

## Использование
FileLogger logger(a.txt, 0); - создание экземпляра логгера, который будет записывать все входящие сообщения в a.txt

запись в журнал:
* logger.Log("b", 1); -> [yyyy-mm-dd HH:MM:SS] [WARNING] b
